# Seedance 2.5 — 微缩场景视频模板

> Preserve the real. Extend the world. Move the camera through it.

独立视频扩展，沿用 [SKILL.md](../SKILL.md) 的 Geometry Lock、光照层级、Surface Interaction 和 Drift Check。仅在用户明确要求视频时使用；不改写静态摄影流程。

## 0. 能力与适用边界

本文是面向 Seedance 工作界面的提示词与制作策略，不是 API 参数或确定性控制协议。“Seedance 2.5”按用户使用的名称记录；具体模型名称、最长时长、多参考图、首尾帧、续接、种子及导出帧率，须以当前平台实际界面为准。未提供的控件不要臆造，时间标记是叙事约束，不保证模型逐秒执行。

单张照片不能证明遮挡后的结构。提示词不能恢复未拍到的楼梯背面、海岸连接处或真实三维路径。需要精确连续穿越时，补拍同一实体模型的重叠视角，或用经核对的三维场景提供相机预演。不要让模型用新道路、桥梁或门洞补齐未知空间。

当前咖啡店示例依据“海岸 → 铁路道口 → 楼梯 → 咖啡店门前”的用户描述，尚未对实际照片进行几何核验。所有示例只在参考图确认路线真实连通后使用；不连通则改走实际通路。

## 1. 视频版 Geometry Lock

静态模板锁定相机位置与构图；视频模板仅允许相机沿批准路径改变位置和朝向。**锁定世界结构，允许符合透视的投影变化。**

| 层级 | 必须保持 | 允许变化 |
|---|---|---|
| 世界几何 | 建筑比例、楼梯级数、道路和轨道连接、码头边缘、栏杆、门窗与道口设备 | 相机位移引起的遮挡、视差和透视 |
| 静止主体 | 人物、绿摩托、蓝货车、树木的位置与身份（仅锁定实际存在的对象） | 视角导致的可见面积变化 |
| 动态例外 | 电车车身、车窗数量、尺寸、所属轨道 | 电车沿同一轨道平移；有可见车轮时合理转动 |
| 摄影 | 原始材质、微缩质感、基准色调 | 平滑且克制的对焦；自然景深随距离变化 |
| 光照 | 太阳世界方向、色温、主辅光关系 | 视角产生的反射变化、移动车辆的接触阴影 |

不要要求移动镜头中的所有像素、构图或景深与首帧完全相同。禁止通过形变、拉伸、瞬移或镜头穿墙来完成路径。美观或运动与结构冲突时，缩短路线或减小运动幅度。

## 2. 生成前：参考图与空间审计

准备以下材料；它们是参考角色，不表示平台一定能同时上传：

- **R0 主几何图**：原始、清晰、未被 AI 改造的全景；呈现海岸、道口、楼梯和咖啡店之间的关系。
- **R1–R3 路线视角**：海岸入口、道口至楼梯脚、楼梯平台至门前，来自同一模型，邻图至少共享两处可辨认地标。
- **L 光影图（可选）**：只提供气氛，不得覆盖几何；已经满意的原图光影无需再重塑。
- **H 交接帧**：上一段验收通过的末帧，仅用于视频续接；仍需对照 R0，防止累计漂移。

核对：路线是否连通；道口与楼梯脚是否在同一侧；楼梯是否可通向目标门；相机能否避开人物、栏杆和列车；隐藏区域是否有参考证据。缺失区域先补拍，不先补写细节。

给地标固定编号：
A 海岸通路起点；B 道口入口；C 道口出口/楼梯脚；D 楼梯上平台；E 咖啡店门前。
记录 A→B→C→D→E 的真实通路、转弯方向与共有地标。未确认左右关系时用地标描述，不猜“左转/右转”。

### 世界方向与屏幕方向

在 R0 中以铁路的两个已知端点定义 T0→T1：T1 是**R0 画面右侧的轨道端点**。电车向 T1 行驶，后续镜头转向时仍保持同一世界方向，不强迫它始终向当前屏幕右侧移动。

太阳定义为 R0 右上方对应的世界方向。镜头转向后高光在画面里的位置可以改变，太阳不能跟着相机旋转。

### 动态物体台账

| 对象 | 默认状态 | 时间/轨迹 |
|---|---|---|
| 电车 | 唯一必要的动态主体 | 自起点沿 T0→T1 缓行，约 15 秒位移半个车身长度；仅为初始调试目标 |
| 人物、绿摩托、蓝货车 | 静止 | 不增加动作、不更换姿势、不复制 |
| 道口栏杆与信号 | 保留参考状态 | 不擅自升降或新增灯光；如果原状态挡路，调整路线 |
| 海水、树叶 | 默认保持克制 | 第一轮不加额外动态，核心验证通过后再逐项允许 |

确保列车不会在相机通过道口时占据同一位置；无法证明安全错开时，让相机停在道口前或修改实际可行路径。电车出画后保留运动状态，重新入画不得重置位置。

## 3. 制作工作流

1. **锁定首帧**：保持原有 golden hour；若需环境延伸，先用静态流程完成并验收，再将结果与原图一起核对结构。
2. **相机单独验证**：电车静止，先做短距离前进测试，确认空间与视差。避免同时加入高速飞行、绕行、变焦、灯光切换。
3. **电车单独验证**：固定相机生成 5 秒，确认车身沿轨道移动。验收后再合并相机和电车运动。
4. **合并验证**：生成下述 15 秒或三个 5 秒片段。固定画幅、色调与实际可用的参数；每次只修改一个主要变量。
5. **时间与结构验收**：先看整体，再逐帧检查遮挡、转弯、出入画和交接点。
6. **失败回退**：结构漂移回到原始参考；不把严重漂移的末帧继续当作下一段起点。

每项单独成功而合并失败时，优先减少并发动作、缩短路径或分段。连续两次出现相同的结构性错误，即暂停抽卡补参考图；这是节省试错的建议阈值，不是模型能力结论。

```text
全程一个连续镜头，无切镜、转场、黑场、闪白或场景重建。最后 [时长] 平缓减速，在 [终点] 停稳。
结构优先于运动，运动优先于气氛。不得通过穿墙、瞬移、形变或新增通路完成镜头。
```

## 5. 咖啡店：15 秒连续镜头

### 路线时间表

| 时间 | 地标/动作 | 约束 |
|---|---|---|
| 0–4 s | A 海岸通路 → B 道口入口 | 起步柔和，保留岸边边缘与道口方向的空间关联 |
| 4–7 s | B → C 道口出口/楼梯脚 | 沿既有通路通过；轨道不断裂；避开电车 |
| 7–12 s | C → D 上平台 | 顺楼梯方向连续升高，不穿过台阶、栏杆或墙体 |
| 12–14 s | D → E 门前 | 门与台阶的连接始终可解释，避开人物与摩托 |
| 14–15 s | E 停稳 | 平缓减速，镜头留在门外 |

这份分配是起始方案。路线实际过长时优先缩短起点距离或分段，不用突然加速强行赶到。

### 可直接粘贴提示词

```text
以提供的同一套 1/64 海边咖啡店模型照片为唯一结构与身份参考，生成 15 秒第一人称低位 FPV 视频，一个连续镜头，从海岸通路经过铁路道口，沿既有楼梯上行，最后停在咖啡店门前。保留微缩实物的材质、建筑比例、门窗、台阶、铁路、道路、道口、码头边缘、树木、人物和道具；照片中可见的绿摩托与蓝货车保持原位。不新建桥梁、道路、台阶或门洞。仅按参考图真实连通的路线运动。

相机保持模型人物视线高度，沿通路稳定前进；爬楼梯时随阶梯连续升高。固定焦段，真实位移产生自然视差，柔和转向，地平线稳定，无翻滚、高速俯冲、急拉远或突然变焦。第一人称画面中不出现身体、无人机或界面。

0–4 秒：从海岸通路起步，缓慢靠近既有铁路道口，岸边与道口的空间关系连续可见。
4–7 秒：沿现有通路通过道口，到达楼梯脚；铁路保持完整，在列车不占据通路的位置通过。
7–12 秒：沿原有楼梯持续上升至咖啡店平台，不越过栏杆，不穿过台阶、墙面或人物。
12–14 秒：从平台缓缓接近原有咖啡店门，保持门外位置，避开原位人物与绿摩托。
14–15 秒：柔和减速并停稳，门前细节保持清晰，无切镜。

电车是唯一主动移动的主体。它从参考起点沿同一条既有轨道，向主参考图右侧的轨道端点缓慢前进；这是固定世界方向，镜头转向后不改变方向。15 秒约移动半个车身长度，连续低速、不倒车、不侧滑、不脱轨；车身尺寸、车窗、涂装与标识不变。镜头与电车不会在道口碰撞；电车自然出画时不强制追踪或复制它，出画不等于停止。

保留原图 golden hour：太阳固定在主参考图右上方对应的世界方向，暖侧逆光和自然阴影延续，不随镜头转动。光作用于现有墙面、轨道、台阶和车身，保留纹理；电车接触阴影随车辆运动，其他阴影保持世界一致。景深随距离平滑变化，转弯时保留足够地标细节，不用强虚化掩盖连接处。

无黑场、闪白、剪切、转场、空间跳跃、场景重建、建筑变形、物体增减、文字重写或凭空新增灯光。几何与真实通路优先；不能完成路线时缩短运动，不通过改造场景完成。
```

## 6. 咖啡店：三个可分段生成的 5 秒版本

这是 **3 × 5 秒**，不是同一条 15 秒的一镜到底证明。分段即使接缝平滑也应标注为分段续接。若平台支持“延长/续接”，优先使用实际可用的该功能；否则导出合格末帧作下一段首帧，并保留原图结构核对。首尾帧控件不存在时不要伪装已设置。

三段共用以下约束块，每段粘贴时先加入它，再加入对应段落：

```text
同一套 1/64 海岸咖啡店实体模型，同一低位第一人称相机、固定焦段与画幅，保持建筑、门窗、楼梯级数、道路铁路连接、码头边缘、人物、绿摩托和蓝货车的世界位置、比例与材质。允许自然透视、视差和遮挡变化。太阳固定在主参考图右上方对应的世界方向；保留原有 golden hour 和表面纹理。相机沿真实通路平滑前进，无穿墙、翻滚、变焦替代位移、黑场、转场或结构重建。
电车仅沿既有轨道向主参考图右侧轨道端点连续缓行，世界方向不变；每段约移动六分之一个车身长度，不重置位置。其他主体静止。出画后不复制电车，不为了展示它改变路线。上一段末帧仅在通过原图结构核对后用于续接。
```

### A 段：海岸 → 道口入口，5 秒

```text
生成 5 秒单镜头。0–1 秒从海岸通路柔和起步，1–4 秒沿原有通路缓缓前进到铁路道口入口，4–5 秒继续同方向低速运动并完成交接，不突然停住。结尾保留道口设备与通向楼梯的可辨认地标；如果原视角看不到楼梯，以同一参考中实际可见的固定地标交接，不凭空新增楼梯。镜头不跨过轨道，不跟拍电车。电车从原始位置开始沿指定轨道缓行。
```

### B 段：道口入口 → 楼梯脚，5 秒

```text
生成 5 秒单镜头。以 A 段合格末帧为起点，首帧匹配相机高度、朝向、焦段、曝光和全部对象状态，继续同一方向与低速，不重新起步。0–3 秒沿既有通路通过道口；轨道、路面和岸边连接连续，不与列车碰撞。3–5 秒柔和朝向真实楼梯脚并接近，结尾可辨认楼梯起点和平台方向，保留低速运动供下一段续接。电车沿上一段轨道位置继续向同一世界端点行驶，不回到原始位置。
```

### C 段：楼梯脚 → 咖啡店门前，5 秒

```text
生成 5 秒单镜头。以 B 段合格末帧为起点，保持相机姿态、前进速度、曝光和电车状态。0–3 秒顺着原有台阶连续上升到平台，不穿栏杆、墙面或台阶；3–4 秒从平台接近咖啡店门外，避开原位人物和绿摩托；4–5 秒平缓减速并停稳。门窗与台阶关系不变。电车如果不在视野中，不新增电车或切回铁路。若实际楼梯长度无法在低速下完成，将本段拆成“上楼梯”和“门前”两段，或缩短已确认可行的起点距离，不瞬移或压缩台阶。
```

### 交接记录

每段记录：末帧、相机高度/朝向、前进方向和速度、两个共同地标、电车相对轨道固定点的位置、光照与对焦状态。下一段先验证首帧再继续。

接缝检查：对照前段最后 0.5 秒与后段最初 0.5 秒，观察地标位置、比例、地平线、运动速度、曝光和电车状态。共享的完全相同边界帧可以去重；剪掉坏帧不能修复拓扑错误。交叉溶解不能作为连续性通过的证据。

## 7. 视频验收标准

以下是本项目建议的人工验收阈值，不是 Seedance 官方指标。先按正常速度看一遍，再按 0.25× 看转弯和遮挡。每秒抽一帧形成联系表，在疑点、道口通过、楼梯上行、接缝处逐帧检查。抽样不能证明没有单帧错误。

### 硬性通过项：全部满足

| 项目 | 验收方式 | 不通过条件 |
|---|---|---|
| 可播放 | 下载原视频后在另一播放器检查，核对时长 | 解码失败、内容缺失；界面预览错误另行排查 |
| 时间 | 导出 15 秒或各 5 秒，允许不超过一个导出帧的取整差 | 明显时长不足，终点未到 |
| 无黑场 | 全片逐帧查可疑片段 | 任一无场景依据的全黑/闪白帧 |
| 路径 | A→B→C→D→E 顺序可辨，相邻区域连通 | 岸边断裂、道口换位置、楼梯突现、瞬移或穿模 |
| 结构 | 与对应真实视角核对门窗、台阶、轨道、栏杆及道具 | 数量改变、增删物体、轨道断裂或建筑变形 |
| 电车 | 在可见区间，以轨道上的固定点观察位置；排除相机视差 | 固定位置不动、倒车、侧滑、复制、重置或脱轨 |
| 光照 | 对照固定建筑面的阴影和高光，考虑自然视差 | 太阳跟镜头转、阴影跳边、纹理被光斑抹掉 |
| 接缝（分段） | 比较交接附近逐帧 | 地标、对象状态、方向或曝光突跳 |

电车建议验收：15 秒可见区间累计相对轨道位移以约半车身为目标，初步容许 0.3–0.7 车身；各 5 秒以约六分之一为目标。若遮挡/出画使位移不可测，标记“未验证”，另做固定相机 5 秒诊断，不凭印象认定通过。车轮不清晰时不要用轮转作为唯一证据。

移动镜头不能与首帧做全画面像素重合检查。应核对物体身份、拓扑、对应视角和局部相对关系；近远地标具有不同视差是正常现象。

### 软性指标：硬性通过后再优化

- 终点至少有最后约 1 秒平稳观赏时间。
- 推进主要由位移产生，转弯前后速度自然，无可见急冲。
- 微缩材质可信，景深不突然泵动，不用过强虚化遮住结构。
- 接缝处作为人工提示阈值：共同地标中心若单帧跳动超过画幅宽度约 2%，或画面整体出现肉眼可见亮度阶跃，进入逐帧复查；这不是自动判定，因为正常运动和遮挡也可能触发。
- 音乐、音效和额外环境动态最后添加，不作为结构连续的证据。

## 8. 故障归因与修复决策

| 错误/诊断证据 | 首选处理 | 何时换参考或策略 |
|---|---|---|
| 黑屏仅在平台预览，下载可播 | 排查预览/播放器 | 与提示词无关，不反复重写路线 |
| 下载视频全黑/解码异常 | 核对输入文件、导出与任务状态，尝试有效图片的短测试 | 文件有效仍失败时换任务/平台流程；“无黑场”不能修复编码故障 |
| 视频出现生成的黑场/转场，但文件正常 | 明确单镜头、去掉“场景切换”措辞和复杂动作 | 重复出现则缩短镜头、采用续接 |
| 电车不动，轨道和车身清楚 | 简化为唯一动态物体，明确相对固定轨道点的位移；固定相机测试 | 车身太小/模糊则补近景；独立测试成功而合并失败则分段或减少运动 |
| 电车方向相反 | 用轨道端点定义世界方向，去掉“每帧向右” | 图中轨道方向不明则补全景/另一视角 |
| 列车侧滑、脱轨或变形 | 减小位移，明确沿轨道纵轴，保持身份 | 轨道被遮挡、弯轨不可见时补图，不能用文字猜轨迹 |
| 岸边断裂、道口与楼梯不接 | 核对路线是否有真实证据 | 优先补重叠视角/缩短路径/三维预演；禁止让 AI 发明连接 |
| 镜头跳跃、穿墙 | 减少转弯、降低速度、用明确地标及时间段 | 原始视角无法支持目标视点则补拍或分段 |
| 门窗/人物/道具漂移 | 取消不必要动态与风格词，从原图重做 | 严重漂移不续接；增加对应视角参考 |
| 光向随相机改变 | 明确固定世界太阳，取消灯光变化指令 | 多图光影冲突时统一时间补拍/选择同一组参考 |
| 三段接缝跳变 | 匹配合格末帧与全部对象状态，减少边界动作 | 无续接支持或大视角变化时接受明确剪辑，或改三维路径 |
| 15 秒赶不到门口 | 减少起点距离、重新分配时间 | 路径长则增加片段数量；不压缩空间 |

### 什么时候提示词已经不够

若路线跨过照片未展示区域、要求较大角度绕到建筑背面，或反复出现相同连接错误，停止堆叠否定词。按优先次序：
1. 补拍同一模型、同一光照的重叠路线视角。
2. 缩短运动，使全过程留在有证据的区域。
3. 用平台实际支持的首尾帧或续接完成分段，并诚实标注分段。
4. 对严格一镜到底需求，用已核对尺寸与通路的三维场景渲染确定的相机路径，再将视频作为受约束参考（仅在平台支持时）；仍须复核 AI 输出。
